# LUMIRA Complete Luxury Jewellery E-commerce Front-End

Open `index.html` in a modern browser. No build step or framework is required.

Included: responsive semantic HTML5, CSS variables, editorial hero carousel, exact wireframe navigation, Lumira 9k, offers, persona tabs, category grid, occasion filters, 12 rich products, model/studio hover crossfade, filters, sorting, search overlay, persistent localStorage cart and wishlist, quantity controls, free-shipping progress, `LUMIRA10` promo, quick view gallery, metal/size selectors, demo checkout, newsletter validation, responsive mobile drawer and footer information modals.

Product/model images currently use `images.unsplash.com` remote URLs. For production, replace them with properly licensed campaign assets served from your own CDN or `/assets` folder. Checkout, tracking, store locator and policy text are front-end demo surfaces and should be connected to production services/legal content before launch.
